# Wiki

The **spaceporn wiki** is a list of GLSL tutorials and online fragment shaders to generate procedural pixelized space content. Shaders documented are or will be integrated in the **spaceporn generator**.

## Before going further

Tutorials are not written by a professional graphic programmer. I did not receive a formal shadering formation. I learned by myself (and from ressources found on Internet). So details are explained the way I understand them. This is why:
- tutorials can leak some knowledges and/or precision,
- articles/tutorials are linked and sourced as mush as possible.

## Prerequites

I assume:
- you have maths knowledges (or at least curious and not afraid about maths),
- you know what is a fragment shader,
- you already have basic knowlegde of shaders. At least about specific types (*vec2*, *vec3*, *vec4*, *ivec2*, *uvec2*, *mat2*, ...) and built-in functions (*abs()*, *sin()*, *floor()*, *fract()*, *length()*, ...).

If not, you can follow this tutorial but it will not be easy. So I advise you to do some reading/testing first.
